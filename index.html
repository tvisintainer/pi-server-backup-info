Pi Server Backup

Pi Server Backup is a personal backup application operated by Thomas Visintainer for his own Raspberry Pi server. It uses restic to encrypt backup data and rclone to transfer it to his Google Drive account.

What the application does

  • Stores encrypted backup snapshots in the owner's Google Drive.
  • Lists and reads repository data to verify backups and restore files.
  • Removes obsolete backup data when the owner runs retention and maintenance operations.

Who can use it

This application is for the owner's personal use. It is not a public backup service and does not offer public registration or Google sign-in on this website.

Google Drive authorization

The owner authorizes rclone through Google's OAuth consent flow. The application uses that authorization for backup and recovery operations. See the privacy policy for details about access, storage and revocation.

This website contains application information only. It does not display backup files, operational logs or server administration tools.

Privacy policy

This policy describes Pi Server Backup, a personal application operated by Thomas Visintainer to back up his own server to his own Google Drive account.

Google data access and use

The application uses rclone and Google OAuth authorization to access Google Drive. Depending on the configured OAuth scope, the granted permission may allow broad Drive access. The intended use is to create, list, read, update and delete the application's backup repository data for backup, verification, recovery and retention.

Backup contents may include personal files, application data and database exports. Restic encrypts backup contents before they are transferred to Google Drive. Google processes account, API-request and storage information as part of providing its services.

Storage and protection

Encrypted repository data is stored in the owner's Google Drive. OAuth credentials and the backup encryption password are maintained on the owner's server in restricted configuration files. Temporary database exports and operational logs may be stored locally during backup processing. Credentials and backup data are not included in this public website.

Sharing

The application does not sell Google user data or use it for advertising. Backup data is transferred to Google Drive to provide the requested storage service. Healthchecks.io is used for job monitoring; job-status check-ins are separate from backup storage. The application is not designed to send backup contents to Healthchecks.io or GitHub Pages.

Retention and deletion

The owner controls backup retention and deletion through restic maintenance commands and Google Drive. Revoking OAuth access stops subsequent authorized access but does not automatically delete existing backups. Existing backup data can be deleted separately by the owner.

Revoking access

The owner can revoke the application's access using Google Account third-party connections. The application must be authorized again before it can resume access.

This website

These informational pages contain no application-added analytics, advertising, cookies, login forms or tracking scripts. GitHub Pages hosts the website and may process visitor technical information under GitHub's privacy statement.

Contact

For questions, contact the application owner using the user-support email displayed on the Google OAuth consent screen for Pi Server Backup. Do not send passwords, OAuth tokens or backup contents in public repository issues.
